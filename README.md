# Calculadora Geométrica — Projeto A3

Projeto acadêmico desenvolvido para a unidade curricular **Projeto A3**. O objetivo é fornecer uma ferramenta capaz de realizar cálculos precisos de área, perímetro e volume para diversas figuras geométricas planas (2D) e espaciais (3D).

---

## Visão Geral

O software é desenvolvido com foco em **Programação Orientada a Objetos (POO)**, garantindo código modular, escalável e de fácil manutenção. A versão inicial prioriza a lógica matemática e a estruturação das classes; a interface gráfica com **Tkinter** está planejada para a etapa seguinte.

> A separação entre lógica de negócio (cálculos) e interface (Tkinter) permite seguir o padrão **MVC (Model-View-Controller)**, facilitando a implementação da GUI sem comprometer a integridade dos cálculos geométricos.

---

## Funcionalidades

| Categoria | Figuras suportadas | Cálculos realizados |
|:---|:---|:---|
| **2D** | Quadrado, Círculo, Triângulo, Pentágono, Retângulo, Losango, Trapézio, Hexágono, Heptágono, Octógono | Área e Perímetro |
| **3D** | Cubo, Pirâmide, Cilindro, Esfera, Cone, Paralelepípedo | Volume e Área Total |

## Como Executar

1. Certifique-se de ter o Python 3.10 ou superior instalado.

2. Clone o repositório:
   ```bash
   git clone https://github.com/Graziel-Silva/Projeto-A3.git
   ```

3. Navegue até a pasta do projeto e execute o arquivo principal:
   ```bash
   python "Projeto A3/Code.py"
   ```
